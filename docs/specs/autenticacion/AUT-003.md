# AUT-003 — Recuperar la contraseña por mail

**Trello:** no tiene tarjeta propia; estaba en el catálogo como R2. Decisión del equipo (Cilento, 26/11/2026): pasa al MVP, porque la app la van a probar personas de afuera y, si alguien se olvida la contraseña, hoy no tiene forma de volver a entrar.

## Historia de usuario
COMO usuario que se olvidó la contraseña QUIERO recibir un link por mail para elegir una nueva PARA volver a entrar sin pedirle ayuda al equipo.

## Criterios de aceptación

```gherkin
Escenario: pedir el link
  Dado que estoy en /ingresar
  Cuando toco "¿Olvidaste tu contraseña?" y escribo mi correo
  Entonces veo "Si el correo tiene una cuenta, te mandamos un link para elegir una contraseña nueva."
  Y me llega un mail con el link a /restablecer, que vence en 60 minutos

Escenario: correo sin cuenta
  Cuando pido el link con un correo que no tiene cuenta
  Entonces veo exactamente el mismo mensaje y la API responde lo mismo (202)
  Pero no se manda ningún mail

Escenario: elegir la contraseña nueva
  Dado que abrí el link del mail
  Cuando escribo una contraseña nueva de 8 o más caracteres y la repito igual
  Entonces la contraseña cambia, quedo con la sesión iniciada y voy a /buscar
  Y veo "Listo, ya cambiaste tu contraseña."

Escenario: link vencido, adulterado o ya usado
  Cuando abro un link que venció, que fue modificado o que ya usé para cambiar la contraseña
  Entonces veo "El link no es válido o ya venció. Pedí uno nuevo." con un acceso a pedir otro

Escenario: contraseña corta o repetida distinta
  Cuando escribo una contraseña de 5 caracteres
  Entonces veo "Le faltan 3 caracteres: el mínimo es 8." (RN-022)
  Y si la repetición no coincide, veo "Las contraseñas no coinciden." sin llamar a la API
```

## Contrato de API

- `POST /auth/recuperacion` `{email}`
  - Responde siempre **202** `{"detalle": "Si el correo tiene una cuenta, te mandamos un link para elegir una contraseña nueva."}`.
  - El mail se manda después de responder, así que el tiempo de respuesta no dice si la cuenta existe.
- `POST /auth/recuperacion/confirmar` `{token, contrasena}`
  - **200** `Usuario` + cookie de sesión.
  - **400** `token_invalido`: "El link no es válido o ya venció. Pedí uno nuevo."
  - **422** `validacion` si la contraseña no cumple RN-022 (`errores` en `contrasena`).

## Diseño (sin cambios en el modelo)

- **El link lleva un token firmado sin estado (JWT HS256, como la sesión de ADR-0005).**
  - Se firma con una clave **derivada** de `SECRET_KEY` y del propósito "recuperacion", así no sirve como cookie de sesión.
  - Lleva el id del usuario, `exp` a los 60 minutos y una **huella**: los primeros 16 caracteres del SHA-256 del hash de la contraseña actual. Cuando la contraseña cambia, la huella ya no coincide y el link queda usado.
  - **No hace falta tabla nueva ni migración.**
- **Mail:**
  - Se manda con la API HTTP de **Brevo** (plan gratis, 300 mails por día). Render gratis bloquea el SMTP saliente (puertos 25, 465 y 587).
  - Variables: `BREVO_API_KEY`, `CORREO_REMITENTE` (un remitente verificado en Brevo) y `URL_PUBLICA` (la base del link).
  - Sin `BREVO_API_KEY`, en desarrollo y en test el mail se escribe en el log. En producción se registra un error, nunca el link, y la respuesta es la misma.

## Entidades
Usuario (solo cambia `hash_contrasena`).

## Reglas de negocio aplicables
RN-022 (contraseña de 8 o más caracteres; mensajes) y RN-036 (link de recuperación).

## Casos borde
- El email se normaliza como en el registro (RN-022).
- Se pueden pedir varios links: todos sirven hasta que venzan o hasta que uno se use.
- Si Brevo falla, se registra el error y la respuesta no cambia: el usuario puede pedir otro.
- El token viaja en la URL del link: el frontend lo saca de la barra de direcciones apenas lo lee (`history.replaceState`).

## Fuera de alcance
- Limitar cuántos links se piden por hora (Brevo corta en 300 mails por día).
- Cambiar la contraseña desde adentro de la cuenta.
- Cerrar las sesiones abiertas en otros dispositivos al cambiar la contraseña: el JWT de sesión no tiene estado y vence solo (8 horas, ADR-0005).

## Dependencias
AUT-001, AUT-002 y ADR-0005.
