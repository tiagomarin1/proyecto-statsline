# BUS-005 — Crear, guardar y cargar el perfil de búsqueda

**Trello:** "Crear perfil de búsqueda" + "Guardar perfil de búsqueda" (Backlog, MVP).

## Historias de usuario
- COMO Director Técnico QUIERO crear un perfil de búsqueda indicando posición, edad y liga PARA ver solo los candidatos que encajan con lo que necesito.
- COMO Director Técnico QUIERO guardar mi perfil de búsqueda PARA reutilizarlo sin volver a cargarlo.

## Criterios de aceptación

```gherkin
Escenario: crear perfil (Trello "Crear" 1)
  Dado que inicié sesión
  Cuando elijo posición, rango de edad y liga y confirmo
  Entonces veo la lista de jugadores que cumplen el perfil

Escenario: campo faltante (Trello "Crear" 2)
  Dado que no elegí liga
  Cuando presiono "Guardar perfil de búsqueda"
  Entonces el campo liga se marca, veo "Para guardar el perfil falta elegir la liga." y no se guarda

Escenario: guardar (Trello "Guardar" 1)
  Cuando presiono "Guardar perfil de búsqueda" con los campos obligatorios completos
  Entonces queda guardado en mi cuenta (PUT /perfil-busqueda)

Escenario: cargar (Trello "Guardar" 2)
  Dado que tengo un perfil guardado
  Cuando presiono "Cargar perfil guardado"
  Entonces se cargan sus filtros (posición, edad, liga y opcionales) y la lista se actualiza

Escenario: reemplazar (Trello "Guardar" 3)
  Dado que ya tengo un perfil
  Cuando guardo otro
  Entonces reemplaza al anterior y veo "Reemplaza al anterior: en el MVP hay un solo perfil."
```

## Contrato de API
`GET /perfil-busqueda` y `PUT /perfil-busqueda`.

## Entidades
PerfilBusqueda.

## Reglas de negocio aplicables
RN-023 y RN-024.

## Casos borde
- Debajo de los filtros se muestra el resumen del perfil guardado: "Perfil guardado: Defensor · 20-27 años · Primera Nacional".
- La ficha usa el perfil guardado para la coincidencia (RN-012).

## Fuera de alcance
Varios perfiles (BUS-008, R2).

## Dependencias
BUS-001 a BUS-004.
