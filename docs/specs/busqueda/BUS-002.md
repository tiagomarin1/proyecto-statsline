# BUS-002 — Filtrar por liga o competición

**Trello:** "Filtrar jugadores por liga o competición" (Garrido + Cilento, vence el 2/11).

## Historia de usuario
COMO Director Técnico QUIERO filtrar jugadores por liga o competición PARA encontrar candidatos sin revisar planillas sueltas.

## Criterios de aceptación

```gherkin
Escenario: elegir una liga (Trello 1)
  Cuando elijo "Primera B Metropolitana"
  Entonces veo solo jugadores cuya estadística vigente (RN-017) es de esa liga

Escenario: sin coincidencias (Trello 2)
  Cuando la combinación de filtros no devuelve jugadores
  Entonces veo "No hay jugadores que cumplan estos filtros" (y la sugerencia de BUS-006)

Escenario: liga sin datos (Trello 3)
  Dado una liga con cobertura "sin_datos"
  Cuando la elijo
  Entonces la respuesta trae liga_sin_datos = true
  Y veo "Todavía no tenemos datos de <liga>" con el botón "Ver todas las ligas"

Escenario: liga con datos básicos
  Dado una liga con cobertura "basica"
  Entonces el selector la muestra como "<liga> (datos básicos)"
  Y sus jugadores llevan el chip "Datos básicos"
```

## Contrato de API
`GET /ligas` y `GET /jugadores?liga_id=`.

## Reglas de negocio aplicables
RN-017 y RN-020.

## Casos borde
- `liga_id` inexistente → 404.
- Sin liga = todas las ligas del MVP.

## Dependencias
DAT-001.
