# UI-005 — Microanimaciones y movimiento coherente

**Trello:** no tiene tarjeta. Sale del pedido del equipo del 27/11/2026.

## Historia de usuario
Como usuario, quiero que la plataforma responda con movimientos suaves a lo que hago, para entender qué pasó y sentirla cuidada.

## Criterios de aceptación

```gherkin
Escenario: un solo lenguaje de movimiento
  Entonces toda la interfaz usa los mismos tiempos y curvas (variables CSS --mov-rapido, --mov-medio, --mov-lento y --mov-curva)
  Y solo se animan transform y opacity (salvo el ancho de las barras de CMP-004)

Escenario: feedback al tocar
  Cuando toco un botón, un chip o una tarjeta
  Entonces hay un estado de presionado y uno de foco bien visible

Escenario: seleccionar para comparar
  Cuando marco un jugador para comparar
  Entonces el check hace un pequeño pop y el contador de la barra de selección rebota

Escenario: seguir o dejar de seguir
  Cuando toco la estrella
  Entonces hace un pop y cambia de color, además del aviso (RN-026)

Escenario: cargando
  Cuando la lista, la ficha o la comparación están cargando
  Entonces veo esqueletos con la forma del contenido, no solo el texto "Cargando…"

Escenario: entrada de las pantallas y de las listas
  Cuando cambio de página o llegan resultados
  Entonces el contenido entra con un fundido corto y las tarjetas con un pequeño desfase

Escenario: reducir movimiento
  Dado que el sistema pide "reducir movimiento"
  Entonces no hay animaciones de entrada, pop ni rebote; los esqueletos quedan quietos
```

## Contrato de API
No aplica (solo frontend).

## Reglas de negocio aplicables
Ninguna.

## Casos borde
- Ninguna animación bloquea la interacción ni retrasa un dato más de 400 ms.
- El hero de UI-003 no cambia.

## Fuera de alcance
- Modo oscuro manual y cambios de paleta (UI-001).
- Estados de error de las pantallas (se mantienen como están).

## Dependencias
UI-001 y UI-002, `hecho`.
